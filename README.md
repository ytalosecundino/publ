# Nexa Tecnologia

Projeto de StartUp para Programação para Web.

Páginas: Início, Sobre Nós, Serviços, Cases e Contato.

Tecnologias: HTML e CSS.

O estilo está no arquivo externo style.css. O projeto utiliza estrutura HTML, tags, links, listas, formulário, seletores CSS, margens, padding, bordas, dimensões, tipografia, fundo, posicionamento e uma Media Query para telas maiores.

Não foram utilizados JavaScript, frameworks ou bibliotecas.
